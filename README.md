Mi nombre es **Chris Rojas** soy un estudiante de la carrera de Ing. en Sistemas Informáticos, este es un repositorio de mi materia de GameDevelopment y subiré todos los proyectos que haga en esta materia.  
A mi me interesan mucho los videojuegos desde que soy pequeño, mi familia tenia un interned cuando era pequeño, de ahí viene mi amor por los juegos, es algo que me encanta, ahora en esta materia de GameDevelopment quiero probar a desarrollarlos y ver que tan bien mi iría en eso.

## Galeria de Juegos  
### Math Runner  
![Runer Juego](https://raw.githubusercontent.com/chrischidori27-debug/Riolu-Studios/refs/heads/main/ProyectosGD/images/juegoRunner.png)
Trata de un pequeño juego donde tienes que seleccionar la opción de correcta como resultado de la operación aritmética mostrada en la pantalla, pierdes cuando ya no te quedan vidas y vas avanzando de nivel si escoges las opciones correctas  
**Genero:** Puzzle  
**Tecnología:** HTML, CSS y JavaScript  
*https://chrischidori27-debug.github.io/Riolu-Studios/ProyectosGD/proyectos/math_runner.html*

### EcoDrop  
![EcoDrop](https://raw.githubusercontent.com/chrischidori27-debug/Riolu-Studios/refs/heads/main/ProyectosGD/images/JuegoEcoDrop.png)
Trata de un pequeño juego al estilo de Guitar Hero donde tienes que poner una basura que aparecerá de la parte superior del juego al envase correspondiente y ganas cuando alcanzas la puntuación correcta.  
**Genero:** Ritmico  
**Tecnología:** HTML, CSS y JavaScript   
*https://chrischidori27-debug.github.io/Riolu-Studios/ProyectosGD/proyectos/EcoDrop.html*

### Educa Pet  
![EducaPet](https://raw.githubusercontent.com/chrischidori27-debug/Riolu-Studios/refs/heads/main/ProyectosGD/images/juegoMascota.png)
Trata de una version simplificada del famoso juego Pou ay que combinaba bien con la tematica de la practica, es un juego donde tienes que cuidar a la mascota y si lo cuidas bien adquieres monedas que puedes gastar en ropa o trajes para tu mascota, y pierdes cuando tu mascota se muere por no cuidarla bien.  
**Genero:** Simulacion, vida  
**Tecnología:** HTML, CSS y JavaScript   
*https://chrischidori27-debug.github.io/Riolu-Studios/ProyectosGD/proyectos/Mascota.html*  
📄 [Ver README del proyecto](ProyectosGD/proyectos/EducaPet/README.md)  
### Reparalo Quispe  
![ReparaloQuispe](https://raw.githubusercontent.com/chrischidori27-debug/Riolu-Studios/refs/heads/main/ProyectosGD/images/juegoSalvalo.png)
Trata de una pequeña pagina web donde esta alojada un juego parecido o inspirado de Repara Felix Jr de la película de Ralph el demoledor, este trata de  un personaje que recorrerá ventanas de un edificio de departamentos donde tienes que reparar tuberías rotas, caeran mejoras en el mapa y pasaras de niveles con mas dificultad.  
**Genero:** plataformero, Arcade  
**Tecnología:** HTML, CSS y JavaScript

### Fresh Flow
![FreshDlow](https://raw.githubusercontent.com/chrischidori27-debug/Riolu-Studios/refs/heads/main/ProyectosGD/images/juegoFreshFlow.png)
Trata de un juego donde tienes que atender un bar para ganar dinero y con ese dinero tienes que mejorar tu local para que vengan mas clientes y el juego gana cuando el local llega a la categoría de una marca internacional, dentro del juego tienes eventos aleatorios donde pueden quitarte dinero.  
**Genero:** Gestion, Desiciones  
**Tecnología:** HTML, CSS y JavaScript   
*https://chrischidori27-debug.github.io/Riolu-Studios/ProyectosGD/proyectos/FreshFlow.html*
